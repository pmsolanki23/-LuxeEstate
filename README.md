# Luxe Estate — Premium Real Estate Frontend

Live Demo: [https://luxe-estate-ecru.vercel.app/](https://luxe-estate-ecru.vercel.app/)

## Overview

Luxe Estate is a modern luxury real estate frontend website built using React and Tailwind CSS. The project is inspired by premium property showcase platforms and focuses on elegant UI, cinematic visuals, smooth animations, and a fully responsive experience.

This project is frontend-only and designed to deliver a high-end luxury real estate browsing experience.

---

# Features

* Fullscreen luxury hero section
* Dark mode & light mode support
* Premium property showcase cards
* Fully dynamic property rendering
* Smooth UI animations
* Interactive map integration
* Responsive design for all devices
* Elegant typography and spacing
* Glassmorphism navigation bar
* Reusable React components
* Modern luxury UI inspired by Airbnb Luxe

# Installation

## Clone Repository

```bash
git clone <repository-url>
```

## Navigate Into Project

```bash
cd luxury-real-estate
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

---

# Build for Production

```bash
npm run build
```
